# Test dependencies for LOCAL use.
#
# pytest-homeassistant, Home Assistant's own test plugin, pulls in a matching
# Home Assistant release plus the fixtures for integrations. It replaced
# pytest-homeassistant-custom-component, which ended with 2026.10 and must not
# be installed beside it.
#
# Deliberately UNPINNED here: locally you want whatever is current, and only a
# current Home Assistant surfaces deprecations and API removals - an old pin
# makes the integration look healthy while it is already broken (an old pin of
# the previous plugin held Home Assistant 2025.6 while users ran 2026.8).
#
# The CI test job does NOT install this file. It installs the plugin directly,
# at a version resolved to a final Home Assistant, plus the minimum lane on the
# old plugin. See .github/workflows/test.yaml and .github/scripts/resolve_phcc.py.
pytest-homeassistant
# The e2e tests rely on `pytest.mark.timeout`; a marker nothing registers is a
# silent no-op. Pinned in requirements_gates.txt with pytest-cov and numpy.
pytest-timeout
# check.sh spreads the suite over the cores with it (`-n auto`); declared
# rather than inherited, like pytest-timeout.
pytest-xdist
# The gates check.sh runs, from the one file CI installs against too - a
# formatter that reflows differently from CI's is a red build nobody changed.
-r requirements_gates.txt
# compile_kennfeld.py draws the preview picture with it; the integration
# itself never imports it.
pygal==3.1.3
-r requirements.txt
